## eslint `-f unix` 훅 오류 (developer 보고)
- 원인은 하네스에 있고 코드와 무관하다. `.claude/hooks/check_edit.py:85`가 `eslint --format unix`를 호출하는데, 설치된 ESLint 9.39.5에는 unix 포매터가 들어 있지 않다. `npx eslint -f unix src/api/client.ts`를 실행하면 "The unix formatter is no longer part of core ESLint"를 출력하고 종료 코드 2로 끝난다
- 같은 파일에 `npm run lint`를 실행하면 통과한다. 따라서 코드 문제가 아니다. 다만 이 상태에서는 편집 훅의 eslint 검사가 사실상 동작하지 않는다. 품질 게이트(`make check`)는 `npm run lint`를 쓰므로 영향이 없다. 하네스 수정은 사용자 권한이다(아래 #6)
