## act 경고 출처
테스트 로그의 "not wrapped in act(...)" 경고는 두 파일에서만 나온다. 나머지 stderr는 React Router v7 future flag 안내(LoginPage·SignupPage·main·App 테스트)이며 결함이 아니다.
- `src/main.test.tsx`: "An update to Root ..." — `/login`, `/signup` 두 테스트. `await import("./main")`을 `act`로 감싸지 않음(#1)
- `src/App.test.tsx`: "An update to AuthProvider ..." — 세 테스트 모두. `getMe` mock이 동기 단언 뒤에 resolve되어 AuthProvider 상태가 테스트 밖에서 바뀜(#2)
