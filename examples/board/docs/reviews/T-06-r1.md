## 확인 요청 (1) pytest 하한
`backend/pyproject.toml:19` `pytest>=9,<10`은 취약 버전을 **막지 못한다**.
- `pip index versions pytest`: 9.0.0, 9.0.1, 9.0.2가 PyPI에 있다
- `packaging.SpecifierSet(">=9,<10")`은 9.0.0·9.0.2를 포함하고, `">=9.0.3,<10"`은 포함하지 않는다
- `pip-audit --no-deps -r`(stdin): pytest==9.0.0, 9.0.2 → PYSEC-2026-1845(수정 9.0.3), pytest==9.0.3 → 취약점 없음

지금 venv는 해석기가 최신 9.1.1을 골라 audit가 통과할 뿐이다. 캐시·미러·제약 파일 때문에 9.0.0~9.0.2가 설치되면 `make audit`가 실패하고 취약 버전이 쓰인다. 설계가 하한을 9.0.3으로 둔 이유(02_design.md:45, :266 "취약 버전 설치를 막기 위함")와도 어긋난다.
