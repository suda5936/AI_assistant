# 사내 게시판 서비스 요청서

## 개요
팀원들이 공지와 잡담을 올릴 수 있는 작은 웹 게시판이 필요합니다. 브라우저에서 쓰고, 회원가입한 사람만 글을 쓸 수 있으면 됩니다.

## 필요한 기능
1. 회원가입: 아이디와 비밀번호로 가입. 아이디는 중복되면 안 됨. 비밀번호는 너무 짧으면 안 됨.
2. 로그인 / 로그아웃. 로그인 상태는 브라우저를 새로고침해도 유지되어야 함.
3. 게시글 목록: 누구나(로그인 안 해도) 볼 수 있음. 최신 글이 위로. 글이 많아지면 페이지로 나눠서.
4. 게시글 상세 보기: 누구나 볼 수 있음. 제목, 내용, 작성자, 작성 시간.
5. 글쓰기: 로그인한 사람만. 제목과 내용 필수.
6. 글 수정 / 삭제: 자기가 쓴 글만 가능. 남의 글은 버튼도 안 보이고, 억지로 요청해도 막혀야 함.

## 기타
- 보안은 기본적인 수준으로 신경 써 주세요 (비밀번호 암호화 등).
- 화면은 깔끔하기만 하면 됩니다. 디자인은 신경 안 써도 됨.
- 댓글, 첨부파일, 검색, 관리자 기능은 이번에는 필요 없습니다.
