## 모듈과 인터페이스

### errors (src/todo/errors.py)
역할: 이 패키지가 던지는 예외. `str(예외)`는 `오류: ` 접두어를 뺀 사용자용 메시지다. 접두어는 cli가 붙인다.

```python
class TodoError(Exception):
    """이 패키지 예외의 기반 클래스."""


class UsageError(TodoError):
    """명령이 없거나, 알 수 없는 명령이거나, 인자 개수가 틀릴 때.
    메시지: '사용법: python -m todo add "<제목>" | list | done <번호> | delete <번호>'
    """


class InvalidTitleError(TodoError):
    """제목 검증 실패. 메시지: '제목을 입력하세요' 또는 '제목은 100자 이하여야 합니다'."""


class TaskNotFoundError(TodoError):
    """번호에 해당하는 할 일이 없거나 번호가 숫자가 아닐 때.
    __init__(self, raw_id: str) - self.raw_id에 보관.
    메시지: f'#{raw_id} 할 일을 찾을 수 없습니다'
    """


class StorageError(TodoError):
    """저장 파일 읽기·쓰기 실패.
    메시지: f'저장 파일을 읽을 수 없습니다: {path}' 또는 f'저장 파일을 쓸 수 없습니다: {path}'
    """
```

종료 코드 매핑(cli에서): `UsageError`, `InvalidTitleError`, `TaskNotFoundError` → 1, `StorageError` → 2.

### models (src/todo/models.py)
역할: 데이터 구조. 동작 없음.

```python
@dataclass
class Task:
    id: int
    title: str
    done: bool = False


@dataclass
class TodoList:
    next_id: int = 1
    tasks: list[Task] = field(default_factory=list)
```

### storage (src/todo/storage.py)
역할: 저장 경로 결정과 JSON 파일 읽기·쓰기. 출력하지 않는다(로그는 `logging.getLogger(__name__)`만).

```python
ENV_VAR: str = "TODO_FILE"
DEFAULT_FILE_NAME: str = "todo.json"


def resolve_path(environ: Mapping[str, str] | None = None) -> Path:
    """저장 파일 경로를 정한다.
    environ이 None이면 os.environ을 쓴다.
    environ[ENV_VAR]가 있고 빈 문자열이 아니면 Path(그 값), 아니면 Path(DEFAULT_FILE_NAME).
    """


def load(path: Path) -> TodoList:
    """저장 파일을 읽어 TodoList를 돌려준다.
    파일이 없으면(path.exists()가 False) TodoList()를 돌려준다. 파일을 만들지 않는다.
    Raises: StorageError('저장 파일을 읽을 수 없습니다: {path}')
        - 02_design.md "손상된 파일의 정의"에 해당할 때
        - path.exists() 호출을 포함한 모든 파일 접근의 OSError
        - json.loads의 ValueError(JSONDecodeError 포함)와 RecursionError
          (RecursionError는 json.loads 호출만 감싸서 잡는다)
    """


def save(path: Path, todo: TodoList) -> None:
    """TodoList를 02_design.md의 형식으로 저장한다.
    순서: ① 저장할 텍스트를 만들고 바이트로 인코딩(.encode("utf-8"), 오류 처리기 기본 'strict')
          ② path.parent에 임시 파일(tempfile.NamedTemporaryFile(dir=..., delete=False))로 바이트를 씀
          ③ os.replace(임시, path)
    ①에서 실패하면 임시 파일을 만들지 않는다. ②③에서 예외가 나면 예외 종류와 관계없이
    임시 파일을 지우고(지우기 실패는 로그만 남김) 예외를 던진다. 폴더는 만들지 않는다.
    Raises: StorageError('저장 파일을 쓸 수 없습니다: {path}')
        - ②③에서 OSError가 났을 때
        - ①에서 UnicodeEncodeError가 났을 때 (제목에 서로게이트 문자 등 UTF-8로 인코딩할 수 없는 문자)
    """
```

내부 도우미(비공개, 이름 자유): dict → TodoList 변환·검증, TodoList → dict 변환.

### service (src/todo/service.py)
역할: 할 일 규칙. 입출력·파일 접근 없음. 전달받은 `TodoList`를 제자리에서 바꾼다.

```python
MAX_TITLE_LENGTH: int = 100


def validate_title(title: str) -> None:
    """제목을 검증한다.
    Raises: InvalidTitleError('제목을 입력하세요') - title.strip() == '' 일 때
            InvalidTitleError('제목은 100자 이하여야 합니다') - len(title) > MAX_TITLE_LENGTH 일 때
    빈 값 검사를 먼저 한다.
    인코딩 가능 여부(서로게이트 문자)는 검사하지 않는다. 그 경우는 storage.save가 StorageError로 처리한다.
    """


def add_task(todo: TodoList, title: str) -> Task:
    """validate_title 후 Task(id=todo.next_id, title=title, done=False)를 tasks 끝에 추가하고
    todo.next_id를 1 늘린다. 추가한 Task를 돌려준다.
    Raises: InvalidTitleError (validate_title과 같음). 예외 시 todo는 바뀌지 않는다.
    """


def list_tasks(todo: TodoList) -> list[Task]:
    """id 오름차순으로 정렬한 새 리스트를 돌려준다(todo.tasks 자체는 바꾸지 않음)."""


def find_task(todo: TodoList, raw_id: str) -> Task:
    """사용자가 입력한 번호 문자열로 할 일을 찾는다.
    raw_id가 re.fullmatch(r'[0-9]+', raw_id)에 맞으면 int로 바꿔 id가 같은 Task를 찾는다.
    ('01'은 1로 본다.)
    Raises: TaskNotFoundError(raw_id) - 형식이 맞지 않거나('abc', '-1', '1.5', '') 해당 id가 없을 때
    """


def complete_task(todo: TodoList, raw_id: str) -> tuple[Task, bool]:
    """find_task로 찾은 할 일을 완료로 바꾼다.
    반환: (task, changed). 이미 완료였으면 상태를 바꾸지 않고 changed=False.
    Raises: TaskNotFoundError
    """


def delete_task(todo: TodoList, raw_id: str) -> Task:
    """find_task로 찾은 할 일을 todo.tasks에서 제거하고 돌려준다. next_id는 바꾸지 않는다.
    Raises: TaskNotFoundError
    """
```

### cli (src/todo/cli.py)
역할: argv 해석, service·storage 호출, 출력, 종료 코드. `print` 허용. `sys.exit`를 직접 부르지 않고 코드를 반환한다.

```python
def main(argv: Sequence[str] | None = None) -> int:
    """CLI 진입점. argv는 프로그램 이름을 뺀 인자(None이면 sys.argv[1:]).
    반환: 종료 코드 (0 성공, 1 입력 오류, 2 저장 파일 오류).
    TodoError 하위 예외를 잡아 print(f'오류: {exc}', file=sys.stderr) 후 해당 코드를 반환한다.
    예상하지 못한 예외는 잡지 않는다.
    """


def format_task_line(task: Task) -> str:
    """목록 한 줄: f'#{task.id} [{"x" if task.done else " "}] {task.title}'"""
```

명령별 동작(검사 순서는 02_design.md "오류 처리" ①~⑤):

| 명령 | 인자 수 | 처리 | 표준 출력 (성공) | 저장 |
|---|---|---|---|---|
| `add <제목>` | 1 | validate_title → load → add_task → save | `추가됨: #<id> <제목>` | 함 |
| `list` | 0 | load → list_tasks | 비면 `할 일이 없습니다`, 아니면 format_task_line 줄들 | 안 함 |
| `done <번호>` | 1 | load → complete_task → changed면 save | changed: `완료: #<id> <제목>` / 아니면 `이미 완료됨: #<id>` | changed일 때만 |
| `delete <번호>` | 1 | load → delete_task → save | `삭제됨: #<id> <제목>` | 함 |

- 인자 수가 표와 다르거나 명령이 없거나 알 수 없으면 `UsageError`.
- 출력의 `<id>`는 저장된 정수 id다(입력 `01`이어도 `#1`). 오류 메시지의 `#<입력값>`만 입력 문자열 그대로.
- 경로는 `storage.resolve_path()`로 매 실행 시 구한다.
- print는 호출 시점의 `sys.stdout`/`sys.stderr`에 쓴다(테스트의 capsys가 잡을 수 있게 모듈 로드 시 스트림을 저장해 두지 않는다).

### __main__ (src/todo/__main__.py)
역할: `python -m todo` 진입점. `raise SystemExit(main())` 한 줄 (`from todo.cli import main`).

## 테스트 작성 시 주의 (developer, qa 공통)
- 테스트는 `tmp_path`에 저장 파일을 두고 `monkeypatch.setenv("TODO_FILE", ...)` 또는 `monkeypatch.chdir(tmp_path)`로 격리한다. 저장소 루트에 `todo.json`을 만들지 않는다.
- 회사 공통 `ruff.toml`은 `tests/` 아래에서 `S603`(subprocess 호출)을 허용하지 않는다. 인수 테스트는 `todo.cli.main([...])` 직접 호출과 capsys를 기본으로 하고, `python -m todo` 진입점(AC-1)은 `runpy.run_module("todo", run_name="__main__")`에 `monkeypatch.setattr(sys, "argv", [...])`를 써서 `SystemExit.code`로 확인한다.

## 통합 검증 시나리오
깨끗한 임시 폴더, `TODO_FILE` 미설정 상태에서 차례로 실행:
1. `list` → `할 일이 없습니다`, 코드 0, `todo.json` 생기지 않음
2. `add "우유 사기"` → `추가됨: #1 우유 사기` / `add "운동"` → `추가됨: #2 운동`
3. `done 1` → `완료: #1 우유 사기` / 다시 `done 1` → `이미 완료됨: #1`
4. `list` → `#1 [x] 우유 사기`, `#2 [ ] 운동`
5. `delete 2` → `삭제됨: #2 운동` / `add "책 읽기"` → `추가됨: #3 책 읽기` (2 재사용 안 함)
6. `done 2`, `delete abc` → `오류: #2 …`, `오류: #abc …`, 코드 1
7. `add ""`, `add "   "`, 101자 → 오류, 코드 1, 파일 내용 불변 / 100자 → 성공
8. `TODO_FILE=<다른 경로>`로 `add` → 그 경로에 저장되고 `todo.json`은 불변
9. `todo.json`을 `{깨짐`으로 덮은 뒤 `list`, `add "x"` → `오류: 저장 파일을 읽을 수 없습니다: todo.json`, 코드 2, 파일 바이트 불변
