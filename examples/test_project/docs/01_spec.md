# test_project 요구사항 명세

- 상태: 승인됨 (사용자 위임에 따라 PM 대행 승인, 2026-10-03)
- 규모: 대 (새 프로젝트)
- 요청 원문: docs/00_request.md

## 목적
터미널에서 할 일을 추가·조회·완료·삭제하고, 프로그램을 다시 실행해도 데이터가 유지되는 CLI를 만든다.

## 범위
- 포함: `add`, `list`, `done`, `delete` 명령, JSON 파일 저장
- 제외: 마감일·우선순위·태그, 여러 사용자, 수정(편집) 명령, 색상 출력, 동시 실행 보호

## 마일스톤
| ID | 이름 | 포함 AC |
|---|---|---|
| M1 | 할 일 관리 기본 기능 | AC-1 ~ AC-10 |

## 완료 기준
- AC-1: 실행 방법은 `python -m todo <명령> [인자]`이다. 저장 파일 경로는 환경변수 `TODO_FILE`, 없으면 현재 폴더의 `todo.json`이다.
- AC-2: `add "<제목>"`을 실행하면 할 일이 저장되고 `추가됨: #<번호> <제목>`을 출력하며 종료 코드 0으로 끝난다. 번호는 1부터 시작해 추가할 때마다 1씩 늘어나며, 삭제된 번호는 다시 쓰지 않는다.
- AC-3: 제목이 비어 있거나 공백뿐이면 `add`는 `오류: 제목을 입력하세요`를 표준 오류로 출력하고 종료 코드 1로 끝나며 아무것도 저장하지 않는다.
- AC-4: 제목이 100자를 넘으면 `add`는 `오류: 제목은 100자 이하여야 합니다`를 표준 오류로 출력하고 종료 코드 1로 끝난다. 정확히 100자는 허용한다.
- AC-5: 할 일이 없을 때 `list`를 실행하면 `할 일이 없습니다`를 출력한다.
- AC-6: 할 일이 있을 때 `list`는 번호 오름차순으로 한 줄에 하나씩 `#<번호> [ ] <제목>` (완료된 것은 `[x]`) 형식으로 출력한다.
- AC-7: `done <번호>`를 실행하면 해당 할 일이 완료로 바뀌고 `완료: #<번호> <제목>`을 출력한다. 이미 완료된 할 일이면 상태를 바꾸지 않고 `이미 완료됨: #<번호>`를 출력하며 종료 코드 0으로 끝난다.
- AC-8: `delete <번호>`를 실행하면 해당 할 일이 삭제되고 `삭제됨: #<번호> <제목>`을 출력한다.
- AC-9: `done`, `delete`에 없는 번호나 숫자가 아닌 값을 주면 `오류: #<입력값> 할 일을 찾을 수 없습니다`를 표준 오류로 출력하고 종료 코드 1로 끝난다.
- AC-10: 프로그램을 다시 실행해도 이전에 추가·완료·삭제한 결과가 그대로 유지된다. 저장 파일이 손상되어 읽을 수 없으면 `오류: 저장 파일을 읽을 수 없습니다: <경로>`를 표준 오류로 출력하고 종료 코드 2로 끝나며 파일을 덮어쓰지 않는다.

## 제약 조건
- Python 3.11 이상, 표준 라이브러리만 사용 (외부 라이브러리 없음)
- 모든 출력은 한국어
